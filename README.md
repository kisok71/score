# score - CaddieMaster (AI 골프 스코어 & 코스 매니저)

골프 전문 캐디 매니저와 함께하는 실시간 스코어 관리, 18홀 코스 공략 시각화 맵 및 투어급 분석 대시보드 모바일 웹 애플리케이션입니다.

## ⛳ 주요 기능

1. **골프 코스 검색 & 원클릭 자동 입력**
   - 국내 15대 명문 골프장 기본 탑재 (사우스스프링스, 잭니클라우스, 아난티, 클럽모우, 해슬리 나인브릿지, 안양 CC, 베어크리크 등)
   - 골프장명, 지역(이천, 가평, 송도, 제주, 포천 등), 권역별 실시간 검색
   - 코스 선택 시 18홀 파(Par 3/4/5), 전장 거리(m), 핸디캡, 해저드/벙커 배치, AI 캐디 공략 자동 세팅

2. **사용자 직접 코스 등록 & 설계 (Custom Course Builder)**
   - 나만의 골프장 및 전반/후반 코스명 자유 등록
   - 원클릭 전장 템플릿(표준 6,400m, 산악형 고저차 코스, 롱 챔피언십 6,750m)
   - 1~18홀별 파, 전장 거리, 도그렉 형태 커스텀 수정 및 로컬 스토리지 영구 보관

3. **듀얼 스코어 입력 & 벌타(OB/해저드) 특설티 처리**
   - 원터치 퀵 스코어 (버디, 파, 보기, 더블, 트리플) 및 퍼트 수 분리 기록
   - 한국 로컬룰(특설 OB티 4th shot, 해저드티 3rd shot) 자동 계산 및 벌타 룰 가이드
   - 언더파 기록 시 폭죽(Confetti) 축하 세레머니 연출
   - FIR(페어웨이 안착), GIR(온그린), 벙커 샷 횟수 및 샌드 세이브 트래킹

4. **18홀 코스 공략 시각화 맵 & AI 캐디**
   - 인터랙티브 SVG 필드 맵: 안전 공략 루트(Safe) vs 공격적 버디 루트(Attack)
   - 사용자 클럽백 비거리(드라이버, 3번 우드, 유틸 등)에 따른 페어웨이 낙구 지점 시뮬레이션
   - 고저차(+/-m) 및 맞바람/뒷바람 세기를 반영한 실제 공략 거리 산출

5. **투어 프로급 분석 대시보드 & 18홀 스코어카드**
   - 전통 18홀 스코어카드 (전반 OUT / 후반 IN 소계, 표준 골프 심볼 표기, SNS 공유 복사)
   - 벌타 제외 잠재 스코어 (Virtual Clean Score)
   - 스코어 분포도, Par 3 / Par 4 / Par 5별 평균 타수 분석
   - 티샷 정확도(FIR %), 그린 적중률(GIR %), 홀당 평균 퍼트 수

6. **전담 AI 캐디 매니저 1:1 대화 (캐디 톡)**
   - 홀별 공략법, 바람/경사 클럽 선택 조언, 미스 샷 후 멘탈 관리법 상담

## 🚀 빠른 시작

```bash
# 의존성 설치
npm install

# 로컬 개발 서버 실행 (포트 5173)
npm run dev

# 프로덕션 빌드
npm run build
```

## 🛠️ 기술 스택
- **Frontend**: React 19, TypeScript, Vite
- **Styling**: Tailwind CSS v4, Lucide Icons
- **Animation**: Canvas Confetti
- **Platform**: Mobile-First PWA (iOS / Android 홈화면 추가 지원)
